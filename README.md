# Zapretik

Умная консольная утилита (Python) для обхода DPI-блокировок **Discord** и **YouTube** в Windows.

Обёртка над [`winws.exe`](https://github.com/bol-van/zapret) — официальный репозиторий [bol-van/zapret](https://github.com/bol-van/zapret)

Идея и набор параметров стратегий взяты из проекта [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (MIT)

</div>

---

## ✨ Возможности

- **Автономность.** При первом запуске Zapretik сам проверяет наличие ядра (`winws.exe`, `WinDivert.dll`) и, если их нет, автоматически скачивает его с GitHub и распаковывает в рабочую папку.
- **Интерактивное меню.** 4 предустановленные стратегии обхода + пункт «Остановить сервис».
- **Права администратора.** Проверка прав через WinAPI и автоматический перезапуск с запросом UAC (winws.exe работает с драйвером WinDivert).
- **Логирование.** Весь вывод `winws.exe` пишется в `zapretik.log` и дублируется в консоль с цветовой маркировкой ошибок.
- **Корректная остановка.** По Ctrl+C или пункту меню процесс `winws.exe` завершается полностью — без зависших процессов и «застрявших» драйверов.

## ⚙️ Использование

### 1. Включите Secure DNS
- **Chrome** — «Использовать безопасный DNS» и выбрать поставщика услуг DNS (любой, отличный от «Поставщик по умолчанию»).
- **Firefox** — «Включить DNS через HTTPS, используя: Максимальную защиту», затем «Выбрать поставщика» и вписать URL вручную, например `https://dns.google/dns-query` (Cloudflare может быть заблокирован).
- **Windows 11** — Secure DNS включается прямо в настройках ОС ([инструкция](https://remontka.pro/dns-over-https-windows-11/)). Рекомендуется, если вы пользуетесь Windows 11.
- **Роутер Keenetic** — включите опцию «Транзит запросов», иначе возможны проблемы с Secure DNS на компьютере.

### 2. Установите зависимости
Нужен Python 3.8+ для Windows. Затем:

```cmd
pip install rich requests
```

### 3. Запустите утилиту
```cmd
python main.py
```

- При запуске без прав администратора Zapretik **перезапустит себя с запросом UAC**.
- При первом запуске **автоматически скачает ядро** (`winws.exe`, `WinDivert.dll`, `WinDivert64.sys`) в папку проекта — если не работает, см. раздел «Частые вопросы».
- Убедитесь, что путь до папки не содержит кириллицу/спец. символы.

## ℹ️ Меню программы

| Пункт | Стратегия | Параметры `winws.exe` |
|---|---|---|
| **1** | **Discord + YouTube (Стандарт)** — фейковая подмена TLS + фрагментация пакетов, порт TCP 443 | `--wsize=2 --split-pos=2 --fake-tls --dpi-desync=fake --filter-tcp=443` |
| **2** | **Только YouTube (Агрессивный)** — перестановка сегментов (reorder) + фрагментация, порт TCP 443 | `--wsize=1 --split-pos=1 --fake-tls --dpi-desync=reorder --filter-tcp=443` |
| **3** | **Безопасный режим (Медленный)** — только фрагментация, без фейковых пакетов | `--wsize=1 --split-pos=1 --filter-tcp=443` |
| **4** | **Остановить сервис** — корректно завершает `winws.exe` | — |
| **0** | **Выход** | — |

Во всех стратегиях дополнительно применяется `--wf-tcp=443` — перехватывается только TCP-порт 443 (меньше нагрузки на процессор).

Работоспособность стратегии зависит от многих факторов (провайдер, тип DPI). **Пробуйте разные стратегии**, пока не найдёте рабочую для вас.

### Остановка
- нажмите **Ctrl+C** в окне Zapretik — сервис остановится корректно;
- либо выберите пункт меню **4. Остановить сервис**.

### Логи и файлы
- `zapretik.log` — весь вывод `winws.exe` (создаётся в папке проекта);
- `winws.exe`, `WinDivert.dll`, `WinDivert64.sys` — ядро, скачивается автоматически.

## ☑️ Частые вопросы и проблемы

### Не работает Discord / YouTube
- Убедитесь, что настроен **Secure DNS** (см. выше).
- Попробуйте **другую стратегию** — например, если YouTube работает на «Стандарт», а Discord нет, попробуйте «Агрессивный» и наоборот.
- Проверьте логи `zapretik.log`: не упал ли `winws.exe` с ошибкой.

### Обход не работает / перестал работать
- Стратегии могут переставать работать после обнаружения DPI. Это нормально — пробуйте остальные стратегии.
- Проверьте, что `winws.exe` реально запущен (в диспетчере задач).
- Убедитесь, что в логике запуска не возникло ошибок: посмотрите `zapretik.log`.
- Попробуйте полную переустановку (см. ниже).

### Как переустановить полностью?
1. Удалите из папки проекта файлы ядра: `winws.exe`, `WinDivert.dll`, `WinDivert64.sys` и `zapretik.log` (при следующем запуске они скачаются заново).
2. Убедитесь, что драйвер WinDivert не остался в службах (см. ниже).
3. Скачайте свежую версию скрипта и повторите запуск.

### Антивирус ругается на WinDivert
- Добавьте папку с Zapretik в исключения антивируса или отключите детектирование PUA (см. раздел «Антивирусы» выше).

### Античит ругается на WinDivert
- Инструкция по скрытию драйвера: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### При удалении WinDivert остаётся в службах
Узнайте название службы:
```cmd
driverquery | find "Divert"
```
Остановите и удалите её (от имени администратора):
```cmd
sc stop название_из_первого_шага
sc delete название_из_первого_шага
```

### Не запускается из-за прав
- Zapretik требует права администратора (UAC). При запуске без прав он сам перезапустится с запросом. Если UAC отключён или запрос отклонён — запустите `python main.py` от имени администратора вручную.
